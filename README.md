## About Me

Security-focused developer. I build tools that test security — both offensive and defensive — and break things to understand how they hold up. Zero trust by default.

Currently focused on:

- **Red team tooling** — C2 agents, EDR evasion research, post-exploitation concepts (authorized testing only)
- **Web security** — CTF challenges, vulnerability research, exploit development
- **Security automation** — Python toolkits for phishing analysis, network monitoring, vuln scanning, log analysis
- **Systems programming** — Rust for lower-level EDR evasion research
