## 🩸 Featured Project — OxBlood

### Operational Exercises & Benchmarking for Live Offensive Operations & Defense

**OxBlood** is a student-focused cyber adversary drill platform designed to provide hands-on offensive and defensive cybersecurity training.

The platform aims to provide controlled lab environments where students can practice realistic cybersecurity scenarios without affecting production systems.

### Core Features

```text
Authentication
│
├── Drill Management
├── Scenario Catalog
├── Virtual Machine Management
├── Flag Submission
├── Scoring & Leaderboard
├── Report Submission
├── Audit Logging
└── Proxmox Integration
```

The long-term goal is to build a practical cyber range where students can experience:

* 🔴 Offensive Security
* 🔵 Defensive Security
* ⚔️ Attack & Defence Exercises
* 🏴 CTF-style Challenges
* 🖥️ Virtual Enterprise Networks
* 📊 Performance Benchmarking
